# 🦉 OpenAI Integration в PM Академии

## Обзор

PM Академия использует OpenAI API (GPT-4o-mini) для обеспечения работы Совуньи 🦉 — AI-ассистента курса, который помогает студентам глубже понять материал по продакт-менеджменту.

## Архитектура

```
Frontend (ai-assistant.tsx)
    ↓
Server (Supabase Edge Function)
    ↓
OpenAI API (gpt-4o-mini)
    ↓
Response → Frontend
```

## Компоненты системы

### 1. **Серверная часть** (`/supabase/functions/server/`)

#### `sovunya-system-prompt.tsx`
Содержит расширенный system prompt для Совуньи с:
- Детальной личностью и стилем общения
- Правилами ответов (3-5 абзацев, примеры из Figma/Notion/Airbnb)
- Списком продуктовых фреймворков (JTBD, RICE, AARRR, North Star Metric)
- Структурой ответов (эмпатия → основной ответ → практический совет)

#### `ai-chat-handler.tsx`
Обработчик запросов к OpenAI:
- Валидация вопросов (минимум 3 символа)
- Использование `fetchWithRetry` для надёжности
- Параметры модели:
  - `model: "gpt-4o-mini"`
  - `temperature: 0.7`
  - `max_tokens: 1200`
  - `presence_penalty: 0.1`
  - `frequency_penalty: 0.1`

#### `ai-helpers.tsx`
Утилиты для работы с AI:
- `fetchWithRetry()` — экспоненциальный backoff при ошибках
- Кеширование ответов (TTL: 24 часа)
- Fallback-сообщения при недоступности API

#### `index.tsx` — основные эндпоинты:
- `POST /ai-chat` — чат с Совуньей
- `POST /evaluate-case` — оценка кейсов студентов
- `POST /capstone/evaluate` — оценка финальных проектов
- `POST /pm-coach` — сократовский PM-коучинг

### 2. **Фронтенд** (`/src/app/components/`)

#### `ai-assistant.tsx`
- Плавающая кнопка с маскотом Совуньи
- Модальный чат с историей сообщений
- Анимации (motion/react)
- Индикаторы загрузки
- Предложения вопросов для начала диалога

#### `OwlMascot` компонент
- SVG-маскот с эмоциональными состояниями:
  - `neutral` — обычное состояние
  - `happy` — радость от правильных ответов
  - `thinking` — обдумывание вопроса
  - `celebrating` — празднование достижений
  - `encouraging` — поддержка студента

## Использование OpenAI во всей архитектуре

### 1. **AI-Чат (Совунья)**
**Файл:** `/supabase/functions/server/index.tsx` → эндпоинт `/ai-chat`

**Контекст передаваемый в промпт:**
- Модуль курса
- Урок (название + до 4000 символов контента)
- История диалога (опционально)

**Пример запроса:**
```typescript
fetch(`/functions/v1/make-server-279b4dfa/ai-chat`, {
  method: 'POST',
  headers: { 
    'Authorization': `Bearer ${publicAnonKey}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    question: "Как применить RICE для приоритизации?",
    lessonTitle: "Приоритизация фич",
    moduleTitle: "Модуль 3: Product Strategy",
    lessonContent: "...[содержание урока]..."
  })
})
```

### 2. **Оценка кейсов**
**Файл:** `/supabase/functions/server/index.tsx` → эндпоинт `/evaluate-case`

**Критерии оценки (1-10):**
- Структура и логика
- Глубина анализа
- Продуктовый подход
- Практичность решения
- Метрики и оценка результата

**Формат ответа:** JSON с детальным фидбеком

### 3. **PM-Coach (сократовский метод)**
**Файл:** `/supabase/functions/server/index.tsx` → эндпоинт `/pm-coach`

Ведёт диалог, задавая вопросы вместо прямых ответов:
- Адаптируется к уровню PM (Junior/Middle/Senior)
- Использует продуктовые фреймворки
- После 4-6 раундов предлагает структурированный анализ

### 4. **Capstone Projects**
**Файл:** `/supabase/functions/server/index.tsx` → эндпоинт `/capstone/evaluate`

Оценивает финальные проекты студентов по 5 критериям (0-5):
- Понимание проблемы и сегмента
- Продуктовый подход и фреймворки
- Метрики успеха
- Практичность и реализуемость
- Глубина анализа

## Конфигурация OpenAI API Key

Ключ хранится в переменных окружения Supabase:

Настроен через `OPENAI_API_KEY` в Supabase Secrets (Dashboard → Settings → Secrets).

**Важно:** Ключ уже добавлен в секреты проекта и не требует дополнительной настройки.

## Оптимизации и надёжность

### 1. **Retry Logic**
Все запросы к OpenAI используют `fetchWithRetry`:
- Максимум 2 повторные попытки
- Экспоненциальный backoff (1s, 2s, 4s)
- Автоматический retry на 5xx и 429 ошибках

### 2. **Кеширование**
Ответы кешируются в KV-store на 24 часа:
```typescript
const cached = await getCachedAIResponse(lessonId, question);
if (cached) return cached;
// ... вызов OpenAI ...
await setCachedAIResponse(lessonId, question, answer);
```

### 3. **Fallback**
При недоступности API возвращаются дружественные fallback-сообщения.

### 4. **Rate Limiting**
- Используется `gpt-4o-mini` для оптимизации стоимости
- `max_tokens: 1200` для контроля длины ответов
- Penalty параметры для уменьшения повторений

## Интеграция с данными курса

OpenAI имеет доступ к:
- **8 файлов данных курса:**
  - `course-data.tsx`
  - `course-data-extended.tsx`
  - `course-data-prototyping.tsx`
  - `course-data-growth.tsx`
  - `course-data-additions.tsx`
  - `course-data-analytics.tsx`
  - `course-data-pmf.tsx`
  - `course-data-new-modules.tsx`

Контент урока передаётся в промпт (до 4000 символов), что позволяет Совунье:
- Отвечать с учётом материала текущего урока
- Приводить примеры, соответствующие уровню студента
- Связывать вопросы с предыдущими темами

## Примеры использования

### Пример 1: Простой вопрос
**Вопрос:** "Что такое JTBD?"  
**Ответ Совуньи:** "Отличный вопрос! 🦉 JTBD (Jobs To Be Done) — это фреймворк, который помогает понять, какую «работу» пользователь хочет выполнить с помощью вашего продукта..."

### Пример 2: Кейс из реальной работы
**Вопрос:** "Как приоритизировать, если CEO хочет фичу A, а данные показывают, что нужна фича B?"  
**Ответ Совуньи:** "Классическая дилемма продакта! 🦉 Здесь важно не противопоставлять CEO и данные, а найти компромисс. Попробуй RICE-фреймворк..."

### Пример 3: Оценка кейса
**Ответ студента:** [250+ символов про решение продуктовой проблемы]  
**Оценка Совуньи:**
```json
{
  "overallScore": 8,
  "criteria": {
    "structure": { "score": 9, "comment": "Отлично структурировано" },
    "depth": { "score": 7, "comment": "Можно глубже проанализировать метрики" },
    ...
  },
  "strengths": ["Чёткое определение проблемы", "Использование RICE"],
  "improvements": ["Добавить больше данных", "Рассмотреть альтернативы"],
  "summary": "Хороший ответ с чёткой структурой. Для улучшения добавьте метрики успеха."
}
```

## Мониторинг и логирование

Все запросы к OpenAI логируются:
```typescript
console.log(`OpenAI API error: ${response.status} ${errText}`);
console.log(`Error in ai-chat: ${err}`);
```

Ошибки обрабатываются gracefully с fallback-сообщениями.
