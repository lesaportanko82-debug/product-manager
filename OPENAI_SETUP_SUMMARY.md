## Где используется OpenAI в курсе

### 1. **AI-Чат (Совунья)** ✅
- Эндпоинт: `/ai-chat`
- Использование: Ответы на вопросы студентов
- Контекст: Модуль + урок + содержание

### 2. **Оценка кейсов** ✅
- Эндпоинт: `/evaluate-case`
- Использование: Автоматическая проверка решений кейсов
- Критерии: Структура, глубина, подход, практичность, метрики

### 3. **PM-Coach** ✅
- Эндпоинт: `/pm-coach`
- Использование: Сократовский метод обучения
- Особенность: Задаёт вопросы, а не даёт ответы

### 4. **Capstone Projects** ✅
- Эндпоинт: `/capstone/evaluate`
- Использование: Оценка финальных проектов
- Критерии: 5 критериев от 0 до 5

## Ключевые возможности

### ✨ Для студентов:
- Получают помощь 24/7 по любому уроку
- Реальные примеры из Figma, Notion, Airbnb, Uber
- Наводящие вопросы вместо готовых ответов
- Эмпатичный и поддерживающий тон

### 🛠️ Технические преимущества:
- **Retry logic** — автоматические повторные попытки при ошибках
- **Кеширование** — экономия на повторяющихся вопросах (TTL: 24ч)
- **Fallback** — дружественные сообщения при недоступности API
- **Health check** — мониторинг статуса OpenAI
- **Модульность** — легко расширяемая архитектура

### 📈 Оптимизации:
- Использование `gpt-4o-mini` для снижения стоимости
- Ограничение длины ответов (1200 токенов)
- Penalty параметры для избегания повторений
- Экспоненциальный backoff при ошибках
