- если callback еще не дошел — показывать статус "проверяем оплату"
- иметь кнопку:
  - перейти в курс
  - вернуться в личный кабинет
  - перейти на страницу входа, если сценарий этого требует

Важно:
эта страница не должна сама подтверждать оплату по факту редиректа.
Факт оплаты подтверждается только через Result URL / server callback.

7. Создать fail page

Эта страница должна:

- предлагать повторить оплату
- предлагать вернуться назад
- не ломать приложение
- не выбрасывать пользователя из текущего auth state
