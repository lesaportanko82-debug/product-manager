🥇 1. Command Palette (Cmd+K) — мгновенная навигация
Проблема: 64 урока в 18 модулях, плюс глоссарий, флешкарты, экзамен, сертификат — пользователю приходится вручную раскрывать модули в сайдбаре и скроллить. При повторном обучении это особенно болезненно.

Решение: Модальное окно по Cmd+K / Ctrl+K с fuzzy-поиском:

Быстрый переход к любому уроку по названию или ключевым словам из контента
Команды: «Открыть глоссарий», «Флешкарты», «Финальный экзамен», «Сертификат», «Закладки»
Контекст: рядом с каждым уроком — иконка ✅ (пройден) / 🔖 (закладка), номер модуля
Недавние: секция «Недавно открытые» вверху списка
Почему это топ-1: Это single most impactful UX-паттерн для контентных приложений. Notion, Linear, Figma, VS Code — все используют его. Сокращает навигацию с 3–5 кликов до 2 нажатий клавиш. Особенно ценно для пользователей, которые возвращаются к конкретным темам.

Реализация: ~200 строк, один компонент command-palette.tsx, Motion для анимации, без внешних зависимостей.

🥈 2. Визуальная карта обучения (Learning Roadmap)
Проблема: Сайдбар показывает линейный список модулей — это функционально, но не вдохновляет. Пользователь не ощущает «путешествие», не видит, как далеко он продвинулся визуально.

Решение: Интерактивная карта-роадмэп как альтернативный вид дашборда (вместо текущего WelcomeView):

Визуальный путь: модули как «островки» на извилистом пути (SVG-путь с точками)
Прогресс-анимация: пройденный участок пути заливается градиентом teal→emerald
Милестоуны: после каждых 3–4 модулей — визуальная «точка достижения» с бейджем
Текущая позиция: пульсирующий маркер на текущем уроке
Hover-детали: при наведении на модуль — мини-попап с прогрессом, названиями уроков, количеством интерактивных заданий
Zoom-уровни: общий вид всего курса ↔ детальный вид одного модуля
Почему это топ-2: Геймификация у вас уже сильная (бейджи, XP, уровни), но ей не хватает визуального якоря. Roadmap превращает абстрактные цифры прогресса в осязаемое пространственное ощущение движения — это ключевой мотиватор в обучении (эффект «endowed progress»).

Реализация: ~350 строк, SVG + Motion, новый компонент learning-roadmap.tsx, переключатель «Список/Карта» в дашборде.

🥉 3. Smart Lesson Transitions + Micro-celebrations
Проблема: Переход между уроками мгновенный (просто ремаунт компонента), отметка «пройден» — молчаливая смена иконки. Нет эмоциональной обратной связи в ключевые моменты.

Решение: Система микро-праздников и плавных переходов:

A. Переходы между уроками:

Slide-анимация контента (влево → следующий урок, вправо → предыдущий)
AnimatePresence с mode="wait" и направлением на основе индекса урока
B. Микро-праздники:

Урок пройден: короткая анимация конфетти (Canvas, 1.5 сек) + звуковой чирп (Web Audio API, опционально)
Модуль завершён: полноэкранная overlay-анимация (3 сек) с бейджем модуля, XP-баром и кнопкой «Перейти к следующему модулю»
Streak milestone (3/7 дней): огненная анимация вокруг streak-счётчика
Уровень повышен: XP-бар с анимацией заполнения + «Level Up!» тост с новым званием
C. Прогресс-кольцо модуля:

В хедере урока: кольцевой SVG-индикатор (как в Pomodoro) показывающий прогресс по текущему модулю — наглядное «осталось N уроков до завершения модуля»
Почему это топ-3: Исследования показывают, что variable rewards (непредсказуемые позитивные подкрепления) — сильнейший мотиватор в обучении. У вас уже есть badge-notifier с toast — но он реактивный. Проактивные celebrations в момент действия создают мгновенную дофаминовую петлю.

Реализация: ~250 строк, Motion + Canvas для конфетти, интеграция в lesson-view.tsx.
